# Out of scope

One file per idea that was considered and rejected, so agents and contributors don't propose it
again. Name the file after the idea (`plugin-system.md`), and use this shape:

```markdown
# <Idea>

<One paragraph: what was proposed.>

## Why this is out of scope

<The reasoning, and what to use instead.>

## Prior requests

- #123: <title>
```
